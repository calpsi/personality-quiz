# Meshy replacement source

User-provided share: https://www.meshy.ai/s/McyqT3

Downloaded the model asset exposed by that share page as `abraham.meshy`. Its header is `MESHY.AI`, not glTF/GLB or ZIP. It has not been imported, converted, decrypted, or substituted into the museum. A standard GLB export from Meshy is needed.

The share page lists 685,078 faces and 342,473 vertices; these are provider metadata, not locally verified mesh counts. Once a standard export is available, preserve the original and make a separate optimised game version.

The page labels the licence Private. This is a user-supplied project reference, not a reusable public-domain download. No broader licence is asserted.

Browser interaction was unavailable because local browser use is disabled in Work settings. The public GLB link returned HTML rather than a downloadable file. Existing Blender assets remain untouched.
